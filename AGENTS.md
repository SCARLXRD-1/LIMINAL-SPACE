
# LIMINAL SPACE — A PLACE THAT SHOULDN'T EXIST

## 1. PROJECT OVERVIEW

LIMINAL SPACE is an experimental, immersive 3D web experience built around surreal architecture, photorealistic environments, psychological atmosphere and interactive exploration.

The project aims to create digital spaces that feel familiar but fundamentally wrong.

The experience should make visitors question their surroundings through carefully designed environments, spatial transitions, lighting, sound and unexpected interactions.

This is not a conventional website, nor should it look like a generic browser-based game.

The environment itself is the interface.

## 2. CREATIVE DIRECTION

The visual identity combines:

- Photorealistic 3D environments.
- Brutalist architecture.
- Liminal spaces and surreal environments.
- Cinematic lighting.
- Realistic PBR materials.
- Volumetric atmosphere.
- Spatial sound design.
- Impossible architectural structures.
- Minimalist typography and interface elements.

The experience should prioritize atmosphere, visual storytelling and immersion over unnecessary interface elements.

## 3. INITIAL DEVELOPMENT OBJECTIVE

The first development milestone is:

### THE ENTRANCE

Create an immersive, first-person navigable environment representing an apparently ordinary but unsettling architectural corridor.

Expected characteristics:

- Detailed architectural geometry.
- Realistic walls, floors and ceilings.
- Fluorescent lighting.
- Carefully designed shadows.
- Atmospheric depth and fog.
- Realistic materials and textures.
- First-person camera.
- Mouse and keyboard navigation.
- Collision detection.
- Stable rendering performance.

The initial milestone must focus exclusively on THE ENTRANCE.

Additional environments will be developed after the first environment reaches the required visual and technical quality.

## 6. DEVELOPMENT APPROACH

Work incrementally and validate every meaningful implementation.

Expected development progression:

1. Development environment and project foundation.
2. Three.js renderer and scene initialization.
3. First architectural environment.
4. Materials, textures and lighting.
5. First-person navigation and collision detection.
6. Atmospheric effects.
7. Interactive elements.
8. Spatial audio.
